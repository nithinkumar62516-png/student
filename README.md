A simple and efficient Student Management System developed using C programming to manage student records through a menu-driven interface.

The project uses structures, pointers, linked lists, dynamic memory allocation, functions, and file handling to store and manage student information such as roll number, name, and percentage.

1.Features

    Add new student records
    Delete student records
    Display all student details
    Modify existing student information
    Save student records to a file
    Menu-driven and easy-to-use interface

  2.Technologies Used

    C Programming
    Structures
    Linked Lists
    Pointers
    Dynamic Memory Allocation
    File Handling

  3.Purpose

This project was developed to strengthen practical knowledge of C programming and data structures, with a focus on linked-list-based record management
